# Hunter Killer for CrewAI

```sh
pip install hunterkiller-crewai==0.1.0
```

```python
from hunterkiller_crewai import create_levels_tool
print(create_levels_tool().run(symbol="BTCUSDT"))
# In a crew: Agent(..., tools=[create_levels_tool()])
```

Free data is 2 hours behind on six coins. The tool returns the API JSON unchanged
as a string. Read the snapshot age, evidence labels and public record. No orders,
model calls or local estimates. HTTP errors raise; there is no automatic retry.
Paid credentials are optional factory configuration, never model arguments.
The package and keyless endpoint must be released before this example works.

[CrewAI tool API](https://docs.crewai.com/en/learn/create-custom-tools).
